# 价值投资 · 中长线决策台

纯前端、零依赖、可离线运行的价值投资辅助原型，专为做中长线价值投资的人设计。

## 功能模块
- **市场冷热总览（首页）**：家庭资产温度计（0–100° 综合配置温度）、沪深300 估值温度计、股债性价比（Fed 模型）
- **宏观资产走势**：沪深300 / 科创50 / 标普500 / 黄金 / 美债 的长期月线走势与历史分位
- **红利股 Top50**：按股息率 / 连续分红年数 / 分红率排序筛选
- **安全边际测算**：分红贴现（Gordon）与「8 折」安全边际双模型对照
- **懒人跟投清单**：按当前温度最低的资产推荐 2–3 只 10 元起投的场外基金，每只附大白话买入逻辑说明书
- **我的持仓**：建仓成本 / 盈亏、分红再投复利曲线（本地保存）

## 数据来源（透明标注）
- ✅ **真实数据**：沪深300、科创50 的月线序列、实时行情、PE/PB 历史分位来自「通达信 tdx-connector」。
- ○ **示例数据**：标普500、美债10Y、黄金长期走势、红利榜、基金映射、持仓测算为示例，已在界面明确标注。

## 运行方式
直接用浏览器打开 `index.html` 即可（无需构建、无第三方依赖）。或本地起静态服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 技术说明
原生 HTML / CSS / JavaScript，图表为内联 SVG 手绘，无任何第三方库与构建步骤。
